# 商场清洁机器人运营管理系统

清洁任务编排与实时运营看板：运营人员按商场楼层和区域配置清洁计划、分配机器人，执行期间实时查看位置/进度/已清洁面积/异常状态，完成后自动生成作业报告。

技术形态（依据架构基线）：React + Vite 单页前端应用，无服务端；全部业务数据保存在浏览器 `localStorage`（键 `cleaning-robot-ops:v1`），同一浏览器刷新/重开页面后仍可读回；机器人执行数据由前端模拟执行器按时间推进产生。

## 运行

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5187）
```

## 开发自检

```bash
npm run typecheck   # TypeScript 类型检查
npm test            # 单元测试（vitest）
npm run build       # 生产构建
```

## 演示流程（验收主线）

1. **创建晚间清洁计划**：清洁计划页填写楼层、区域、作业时间（默认当天/次日 22:00）、清洁模式并保存；创建后自动进入计划详情，可重新打开核对字段一致。
2. **分配机器人**：计划详情页从机器人清单选择机器人并确认；分配后任务立即进入执行状态（同一机器人不可重复分配）。
3. **查看实时进度**：实时看板页（或计划详情页）每 500ms 刷新，展示当前位置（楼层·区域·路线站点）、任务进度、已清洁面积、异常状态；执行中期有两类模拟异常，异常期间进度暂停并记录事件。
4. **完成并查看报告**：进度到 100% 后任务自动完成并生成作业报告；作业报告页可查看已清洁面积、执行时长、异常记录等。刷新页面不会丢失执行进度（按执行起点恢复）。

## 目录结构

```
src/
  types.ts                 数据模型（计划/机器人/执行/报告）
  data/                    楼层区域目录、内置机器人清单（演示种子数据）
  lib/                     存储适配（localStorage/内存）、格式化、定时器
  simulator/simulator.ts   模拟执行器：纯函数推导进度/位置/面积/异常/事件
  store/store.ts           单一读写边界：localStorage 持久化与业务动作
  store/useStore.ts        React 状态绑定（useSyncExternalStore）
  components/              计划表单、机器人分配、实时看板卡片、报告详情等
  pages/                   清洁计划、计划详情、实时看板、作业报告
tests/                     单元测试（store / simulator / format）
```

## 边界

- 不包含服务端/API、认证权限、后台任务、外部系统集成、机器人档案管理、报告导出、按作业时间自动调度（架构基线 §6 明确不实现）。
- 已清洁面积以「区域面积 × 任务进度」为口径；清洁模式为自由文本（提供常用模式快捷填入，不预设固定清单）。
- 浏览器端完整流程验收由 QA 按验收计划执行。
